# Clarifications — Config UI

## Session 2026-06-06

- Q: Phạm vi config UI ở MVP? → A: Tất cả values
- Q: Config UI mở bằng cách nào? → A: Right-click tray → Settings...
- Q: Cách user chỉnh hotkey trong UI? → A: Capture key trong window
- Q: Config file location? → A: JSON ở platform config dir

## Config fields (tất cả hardcoded values)

- `hotkey` — ví dụ `Cmd+Shift+T`
- `auto_dismiss_secs` — ví dụ `5`
- `target_language` — ví dụ `vi` (Google tl=)
- `max_chars` — ví dụ `5000`
- `timeout_secs` — ví dụ `5` (HTTP)
